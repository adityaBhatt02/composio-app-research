What the agent does automatically

For each app: tries multiple URL patterns to find developer docs, scrapes and cleans the page content, sends it to Google Gemini with a structured JSON output schema (response_schema), extracts auth/access/API/MCP/buildability fields, saves results incrementally (crash-safe). Supports resume from any point.

Where a human was needed

Gated apps: Apps behind partner agreements or sales walls (DealCloud, PitchBook, Gladly) couldn't be fully researched — noting "gated" IS the correct finding.

Ambiguous docs: Some apps have confusing auth docs (multiple methods, unclear which is primary). The verification pass catches most of these.

MCP/Composio status: Whether a community MCP server exists is hard to verify automatically — these had the lowest field accuracy.

Verification & Accuracy

A second agent re-researched a stratified sample (2 per category) and compared field-by-field.
